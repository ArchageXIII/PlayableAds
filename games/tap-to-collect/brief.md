# Pocket treasure

Reference game demonstrating a short, easy-to-understand tap mechanic. Collect eight gold coins in 20 seconds; time begins on the first gameplay input. A two-column grid reflows with the canvas dimensions and preserves collected coins through rotation. Success occurs at eight collected coins; timeout is failure. Both outcomes show replay and a later user-initiated installation button. Optional short synthesized sounds confirm collection. Artwork is a small embedded PNG generated by tooling/sample-art.ts.

Audience: general casual-game players. No real release app is configured. Preview destinations are placeholders and release platform checks are pending. Local acceptance covers both exports, responsive layouts, gestures, pause/resume, sound/mute, success, failure, replay and intercepted CTA dispatch.
