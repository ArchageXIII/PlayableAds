# Shape shuffle

Reference game demonstrating drag/drop and cancellation. Place six gems in their matching coral, mint or blue trays within 30 seconds. Time begins on the first gameplay input. Incorrect drops return the gem to its original position. Rotation or host hiding cancels an active drag while preserving completed placements. Success occurs at six correct placements; timeout is failure. Both outcomes show replay and a later user-initiated installation button. Optional synthesized sound confirms each correct placement; three small embedded PNGs exercise multiple assets.

Audience: general casual-game players. No real advertised app is configured. Preview destinations are placeholders and platform checks are pending. Local acceptance includes incorrect/correct sorting, rotation, success/failure/replay, host lifecycle, sound and CTA dispatch. For a real campaign, add distinct shapes or symbols as well as colours for accessibility.
