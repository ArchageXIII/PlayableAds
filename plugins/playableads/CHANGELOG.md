# PlayableAds plugin changelog

## 0.2.1

- Authoring and verification guidance for automatic export manifests on supporting checkouts.
- Rebuild missing or invalid manifests; distinguish content hashes from complete artifact hashes and unsigned metadata from independent compliance checks.

## 0.2.0

- Universal Google ZIP guidance, platform-selective builds and schema-2 report migration.
- Google-only release builds no longer require Unity store configuration; campaign/device verification remains required.
- Inspect checkout capabilities before using new flags; never silently upgrade an older project.

## 0.1.0

- Initial optional plugin with setup, authoring and export-verification skills.
- Repository marketplace for desktop and CLI installation.
- Uses the selected checkout's commands and documentation; plugin updates do not modify game projects.
